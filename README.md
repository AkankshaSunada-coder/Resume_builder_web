# Resume Builder Project

Welcome! This repository is for Akshatha and friends to collaborate on building a Resume Builder web application.  
It includes frontend pages, templates, and backend logic to practice GitHub workflows and teamwork.

---

## 📂 Project Structure

- `frontend/` → Main pages (index, profiles, notifications, styles, scripts).
- `templates/` → Resume templates (modern, classic, minimal, etc.).
- `backend/` → Server-side code (optional, for future features).
- `docs/` → Documentation and guides.
- `README.md` → Collaboration instructions.
